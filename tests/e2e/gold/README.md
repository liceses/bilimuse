# gold 校准基准标注文件说明

每个文件一个歌（如 `G01.json`），人工标注标准时间戳。结构：

```json
{
  "id": "G01",
  "name": "周杰伦-晴天",
  "artist": "周杰伦",
  "bvid": "BV...",
  "cid": 123,
  "format": "m4a",
  "language": "zh",
  "lyrics": [
    [12.35, "窗外的麻雀"],
    [16.10, "在电线杆上多嘴"],
    ...
  ]
}
```

- `lyrics` 为 `[时间秒, 一行歌词]` 的有序数组，时间来自音频实际演唱时刻。
- 由 `align_bench.py` 读取：输入该歌词（零时间戳）→ whisper 强制对齐 → 与标注时间对比 → 中位误差评级（≤1.5s 优 / ≤3s 过 / >3s 败）。
- bvid/cid 需指向含该歌纯音频的 B 站视频；音频不入库，运行时按需下载。
