  - 原生单页 HTML+JS，零构建 ✅

## 方案与思路

- 进度推送：**WebSocket**（决策）——复用 pipeline `on_event`，每事件 `ws.send_text(json)`，前端逐条渲染。
- 前端：**原生 HTML+JS 单页**（决策，零构建随包分发）——搜索框→结果表（点击行下载）→状态行/进度条/日志。
- 依赖：可选 extra `[web] = fastapi/uvicorn/websockets`（同 [tui] 思路）。
- 事件序列化：`_serialize()` 递归把 pydantic 模型（SongMeta/Lyric）转 dict，避免 `json.dumps` 炸。

## 技巧

- 事件复用：WebSocket 只是 pipeline `on_event` 的另一个"显示器"，与 CLI `_echo_events`/TUI `_log_event` 完全同构 → `web.py:ws_download`
- FastAPI `TestClient` 测 WebSocket：`with client.websocket_connect("/ws/download") as ws: ws.send_json(...); ws.receive_json()` → `tests/test_web.py`
- 前端 `escapeHtml` 用 DOM 转义防 XSS（标题来自网络）→ `app.js`

## API / 库 速查

- `fastapi.WebSocket`：`await ws.accept()/receive_json()/send_text()`；`WebSocketDisconnect` 捕获断开 → `web.py`
