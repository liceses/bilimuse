## 目标与验收

- 目标：所有运行时文件可放项目目录内（不污染系统环境），整个文件夹拷走即用
- 验收标准：
  - `.portable` 标记 / `MUSICALBILI_PORTABLE=1` 环境变量两种触发 ✅
  - 便携下 config/logs/db 统一到项目 `data/` ✅
  - `bilimuse portable on/off` 命令，on 时迁移现有配置(含登录态) ✅
  - `doctor` 显示模式（便携/标准）+ 配置目录 ✅
  - setup.ps1 `-Portable` / setup.sh `--portable` ✅

## 方案与思路

- **单一枢纽**：`default_config_dir()` 是 config/db/logs 的唯一派生源头，只改它一处，`db.py`/`logging_setup.py`/`Config`/`web` 全部自动跟随。
- 优先级：`MUSICALBILI_CONFIG_DIR`（显式覆盖）> 便携（`.portable` 标记 / env）> 平台目录（APPDATA/XDG）。
- 便携目录：项目根 `data/`（config.json / downloads.db / logs/）。`downloads/`、`models/`、`.venv/` 本就项目内，不变。
- `portable on` 迁移：标记创建前取 `default_config_dir()`（=标准目录），把 config.json 复制到 data/（保留登录态），`--no-migrate` 跳过。
- `.portable` 加 .gitignore：克隆默认标准模式，用户按需开启。

## 技巧

- `Path(__file__).resolve().parents[1]` 定位项目根（`bilimuse/` 包的上层），editable 安装下即项目目录 → `config.py:project_root`
- `marker.touch()` / `marker.unlink()` 管理 `.portable` → `cli.py:portable_on/off`
